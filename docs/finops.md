
# FinOps Notes

## Cost Control Principles

- Start locally before using Azure.

- Use short-lived Azure environments.

- Prefer minimal SKUs.

- Apply tags to all resources.

- Destroy resources after each lab session.

- Avoid managed services unless they add clear learning value.

## Azure Resource Lifecycle

Every Azure deployment must include:

1. Creation command

2. Validation command

3. Destruction command

4. Cost notes

5. Known cleanup risks
